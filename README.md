# Renovo Room Blueprints

Make a website for an AI called Renovo. The ai mainly specializes in detailing materials needed and steps for a home renovation. The user must first post an image of the original layout and what they want renovated. They should also mention their location and constraints of where they live, along with the budget. The ai then lists prices for materials and diagrams with measurements with a batch of steps for renovation. At the end of the steps, it shows a diagram of the image sent and a generated image of the finished renovation. If the person doesn't like the result, they have the option to either go with the current idea or change it with more steps later so that it produces a desired result. The person can do this indefinitely. In the middle of the website, there is a title for the website with a caption, both in the color #f9610a. #f9610a will also be used for other elements that should be lighter in color. #5e1f1a will be used for darker elements. There will four text boxes. the first will be for constraints, which is not required. The second will be location, which is mandatory, as well as the image box for images and text box for renovations required. Above the first box, there will be examples you can autofill to test. On the sidebar there will be a list of the tabs you made for renovations. #ffbe96 is used for the text color of regular text. The background is a faded orange to maroon gradient similar to the one used for loveable. The UI style will also be similar to loveable.
